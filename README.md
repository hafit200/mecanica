# Auto Repair Shop Management System 🛠️🚗

## Overview
An individual Java application integrated with MySQL, created to manage and automate daily operations for automotive repair shops, service logs, and client history.

## Key Features
* **Vehicle & Client Management:** Detailed tracking of client history, vehicle specifications, and active repair status.
* **Service & Repair Logging:** Creation of work orders, parts usage, and labor cost estimates.
* **Inventory Control:** Real-time auto parts stock tracking linked to database records.
* **OOP & Relational Data:** Built using Object-Oriented Programming (OOP) principles and persistent MySQL tables.

## Tech Stack
* **Language:** Java
* **Database:** MySQL
* **Tools:** Git, GitHub, Java IDE
